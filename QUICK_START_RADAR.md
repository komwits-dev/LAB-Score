# Interactive Radar Compare tab

After the pipeline completes, open:

```bash
results/12_report/LAB_score_report.html
```

The **Radar Compare** tab lets you:

- search by genome, species, strain, tier, or safety status;
- select any strains for radar comparison;
- use quick presets such as Top 5, Top 10, or Elite;
- click **View** or click a radar trace to open the full strain report;
- export the radar figure as PNG or SVG;
- export the selected-strain comparison table as TSV;
- export an HTML report for one strain or all selected strains.

The radar values are normalized as percentage of the dataset maximum for each functional module, making strain profiles directly comparable across the dataset.
